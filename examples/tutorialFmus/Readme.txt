Dahlquist.fmu and Feedthrough.fmu are FMI 3.0 Co-Simulation FMUs from the FMI standard's Reference FMUs, release 0.0.42
(https://github.com/modelica/Reference-FMUs), shipped for the tutorial "Take a model out as an FMU and back", which puts them in
the library to connect them. They are the release's own archives with the binaries for WebAssembly and 32-bit Windows left out;
nothing else is changed. They carry no binary for Intel Macs. License: LICENSE.txt (2-Clause BSD).
