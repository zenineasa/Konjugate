Third-party code in examples/pidController/PidController.fmu

The FMU was made by OpenModelica 1.27.1 from examples/pidController/PidController.mo (see the README beside it). Its sources/ folder holds the C code OpenModelica generated and the parts of its simulation runtime the FMU needs, and its binaries are compiled from those sources. Besides Konjugate's own model, it carries the code below, under the licences reproduced here. Its libcsv header, which no source includes and no binary compiles, is left out of the FMU.
